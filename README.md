# Sevalaya Hospital (सेवालय आँख अस्पताल)

Official website for **Sevalaya Hospital**, dedicated to comprehensive eye care, clinical ophthalmology, and outpatient diagnostics.

![Sevalaya Hospital](public/assets/hospital-hero.jpg)

## 👁️ Features

- **Compassionate Eye Care Hero & Introduction**: Two-column layout with authentic clinical photography, editorial typography, and quick consultation actions.
- **10 Core Clinical Eye Care Services**:
  1. Computerised Eye Test (कंप्यूटरीकृत आँख जाँच)
  2. Cataract Surgery (मोतियाबिंद का ऑपरेशन)
  3. Pterygium Treatment (नाखूना / परवाल का इलाज)
  4. Glaucoma Treatment (काला मोतिया का इलाज)
  5. General OPD (सामान्य ओपीडी)
  6. Emergency Eye Services (आपातकालीन नेत्र सेवा)
  7. In-House Pharmacy (दवाखाना)
  8. Retinal Examination & Treatment (पर्दा जाँच एवं इलाज)
  9. Spectacle & Lens Services (चश्मा एवं लेंस)
  10. Pediatric Eye Examinations (बच्चों की आँख जाँच)
- **Clinical Facilities & Schedule**: Complete overview of diagnostic infrastructure and daily specialist availability (Daily 9:00 AM – 7:00 PM).
- **Appointment Booking & WhatsApp Click-to-Chat**:
  - Interactive form with validation for Indian mobile numbers and appointment dates.
  - Generates pre-formatted WhatsApp message directly to hospital reception helpline (`+91 70042 14800`).
  - Alternative direct telephone booking option.
- **Multi-Lingual Support (3 Languages)**:
  - **English (`EN`)**
  - **Hindi (`हि`)** (Devanagari, matching hospital posters)
  - **Nagpuri / Sadri (`नाग`)** (Regional language of Chotanagpur / Jharkhand / Bihar)
- **Dark & Light Mode**:
  - System preference detection (`prefers-color-scheme`).
  - Persistent user choice in `localStorage`.
  - Ophthalmologically soothing low-glare dark palette (`#0B0F19`, `#111827`, `#162032`, `#F1F5F9`) designed specifically for light-sensitive patients.
- **Accessible & Responsive**:
  - Accessible mobile drawer with keyboard focus management and Escape key handling.
  - Floating WhatsApp click-to-chat button.
  - Interactive Privacy Policy & Terms of Service dialogs.
  - Smooth scrolling navigation with no broken links.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/weber011/sevalaya-hospital.git

# Navigate into the project folder
cd sevalaya-hospital

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will be running at `http://localhost:3000`.

### Building for Production

```bash
npm run build
```

The output will be generated in the `dist/` directory.
